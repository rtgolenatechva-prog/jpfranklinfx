# AIAgentic Workflow AI

AI-powered SaaS platform built with Next.js, Supabase, and multi-LLM orchestration. Features an AI Receptionist demo, AgenticAI CRM landing pages, and agentic workflow automation.

## Stack

- **Frontend:** Next.js (App Router), Tailwind CSS, shadcn/ui
- **Backend:** Supabase (auth, RLS, realtime), PostgreSQL
- **AI:** Multi-LLM orchestration, agentic workflow pipelines
- **Deployment:** Vercel

## Features

- AI Receptionist landing page (`/plumbing-demo`)
- AgenticAI CRM pricing tiers ($97 / $297 / $497)
- Agentic workflow automation layer
- Supabase authentication and RLS policies

## Getting Started

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Environment Variables

See `.env.example` for required variables. Never commit `.env.local`.
